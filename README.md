# Nusantara Culinary Alchemist

*A Sketchbook of Lost Flavors*

## Tentang Game

**Nusantara Culinary Alchemist** adalah sebuah permainan bertema meracik resep (alchemy) di mana kamu berperan sebagai *Sang Alchemist*. Misi utamamu adalah memulihkan kembali resep-resep masakan khas Nusantara yang telah lama hilang.

Dalam permainan ini, kamu akan diajak bereksperimen dengan berbagai kombinasi bahan makanan lokal, bumbu-bumbu tradisional, hingga teknik memasak untuk menciptakan hidangan-hidangan melegenda dari seluruh penjuru Indonesia.

## Konsep Bermain

Untuk menemukan sebuah resep yang hilang, Sang Alchemist harus menggabungkan tiga elemen utama di atas Kanvas Pencampuran:
1. **Lauk & Karbo (🍗)**: Bahan dasar masakan seperti Ayam, Sapi, Ikan, Nasi, atau Mie.
2. **Bumbu (🧄)**: Rempah-rempah pemberi citarasa khas, seperti Bawang Merah, Bawang Putih, Cabai, Santan, atau Kecap Manis.
3. **Proses (🍳)**: Metode memasak yang digunakan, seperti Goreng, Rebus, Bakar, atau Asap.

Jika kombinasi (racikan) kamu benar, resep rahasia akan terbuka dan masuk ke dalam Buku Resepmu. Jika salah, masakanmu bisa jadi gosong! Tapi jangan khawatir, jika kamu gagal beberapa kali, akan muncul petunjuk *(hint)* misterius untuk membantumu.

## Fitur Utama

- **Sistem *Rarity***: Setiap resep memiliki tingkat kelangkaan berdasarkan seberapa kompleks bahan yang digunakan, mulai dari *Common*, *Rare*, *Elite*, *Epic*, *Legendary*, hingga tingkat *GOD*.
- **Buku Resep Alchemist**: Sebuah koleksi ala buku sketsa (*sketchbook*) tempat kamu menyimpan resep-resep yang berhasil ditemukan lengkap dengan sejarah dan profil citarasanya.
- **Quest Log**: Pantau terus progres penemuan resepmu berdasarkan tingkat *rarity*.
- **Desain Klasik**: Mengusung tema *sketchbook* dan warna sepia yang membawamu bernostalgia ke masa lalu.

## Run Locally

Ini adalah aplikasi berbasis **Next.js**. Berikut cara menjalankannya di perangkatmu:

**Prerequisites:** Node.js

1. Clone repositori ini dan masuk ke dalam foldernya.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan aplikasi:
   ```bash
   npm run dev
   ```
4. Buka [http://localhost:3000](http://localhost:3000) di browsermu untuk melihat hasilnya.
